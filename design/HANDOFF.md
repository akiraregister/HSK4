## 5. 実装するときの落とし穴

- 画面遷移は必ず `goView()` を通す（`currentView` 1つで持つ設計）。新しい画面（完了・価格）も値を足して同じ経路に乗せる
- `LESSONS.length` ではなく `TOTAL_DAYS`（固定90）を使う。未購入だとDay8-90は存在しない
- **`state` に新しいフィールドを足したら `normalizeStateForCloud()` にも足すこと。**
  忘れるとFirebase同期で消える（enumerateしている）
- **ストリークには完了日時が要る。** いまの `state.completed` は `{day:true}` だけで日付を持たない。
  **過去の完了日は復元できない**ので、入れるなら「今日から記録」になる。早く入れるほどよい
- ~~下タブ化は `tests/nav-test.mjs` が落ちる~~ → 対応済み（フェーズ3）。
  **Day学習中は下タブが隠れるので、テストから `#homeBtn` を押せない。** 戻るときは `#topBack`
- 変更したら必ず `node tests/run.mjs`（6スイート）を通す
- **Claude Code on the web（コンテナ）で画面を撮るとき**は2つ引っかかる。手元のMacでは起きない
  - Playwright の Chromium は `HTTPS_PROXY` を見ないので、`chromium.launch({proxy:{...}})`
    で渡す。そのとき `bypass:'127.0.0.1,localhost'` を付けないとローカルの静的サーバーへの
    リクエストまでプロキシに食われる
  - それでも Google Fonts はプロキシのCAを Chromium が信用せず読み込めない。
    **撮れた画像の書体はフォールバックなので、明朝の出来はコンテナでは確認できない**
- 書体：丸ゴシックは使わない方向になった（案Xは明朝）。`--font-brand` `--font-display` の扱いを整理すること
