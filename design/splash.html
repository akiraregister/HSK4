起動スプラッシュ — 絵コンテ（ゆらめき入り）

A案「火が灯る」を長くして、炎のゆらめきを足したもの。見えているのは約1.35秒。タップで即スキップ。

1. コマ割り

火が灯る → 字が組まれる → 炎がゆらぐ → 消える。左から右へ時間が進みます。

2. タイミング

時間対象動き
0 → 60ms—地だけ。読み込みのゆらぎを吸収する間
60 → 420ms炎芯から灯る（下端を軸に小さな種火がふくらむ）
200 → 660ms加油字間が .5em → .18em に締まりながら現れる
420 → 780ms副題淡く現れる
420 → 1500ms炎ゆらぐ（約1.1秒。山と谷の幅を不均等にして機械的に見えないようにする）
1350 → 1700ms全体フェードアウト
1700ms全体DOMから取り除く
長さについて。これは毎日開くアプリなので、長くするほど「今日の15分」を始めるまでの摩擦になります。 1.35秒を標準に置きましたが、下のボタンで 短め(1.0秒) / 標準(1.35秒) / 長め(1.8秒) を切り替えられます。 実機で触って、待たされる感じが出ない上限を決めてください。

3. ゆらめきの違い3案

火の灯り方は共通（芯から）。ゆらぎ方だけが違います。見比べられるように、この見本は最後のフェードアウトだけ省いて完成形で止めてあります（本番は1700msで消えてアプリ本体へ渡ります）。

4. 初回訴求のアニメーション3案

初回起動のときだけ、級診断の前に出ます。1回しか見ないので、スプラッシュより少し丁寧に動かせます。3案とも1画面に収まること（スクロールさせないこと）を条件にしています。

5. 実装するときの約束

  • 操作を絶対に邪魔しない。スプラッシュは pointer-events:none。タップは下のUIへそのまま通り、同時にスプラッシュが消える
  • 動きを止めている人には動かさない。prefers-reduced-motion が有効なら、ゆらめきも含めて静止したまま出して消える
  • ゆらめきは transform と filter だけで書く。レイアウトを動かさないので、古い端末でもコマ落ちしにくい
  • B-3の「ほのかな灯り」は案Xの「影ゼロ」から外れる。起動の一瞬だけの例外として許すかどうかの判断が要る
  • 炎の形と色はアプリアイコン（O7）と同じものを使う。別に作らない
  • テストへの影響。初回訴求を足すと初回の入口が1段増えるので、共通のヘルパーで吸収する
