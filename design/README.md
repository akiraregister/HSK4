# アプリ改修案のモックアップ

`design/index.html` を Safari で開くと、改修後の画面を実際に触れます。
**アプリ本体（`../index.html`）にはまだ一切手を入れていません。**
画面の形と流れを実装前に決めて、作り直しの無駄をなくすためのものです。

- 上の「いま / 改善案」で現行画面と見比べられます（現行は `current/*.png`）
- 改善案の側はボタンが動きます。今日 → 学習 → ミニテスト → 完了 と辿ってみてください
- 色・書体はアプリと同じトークンを共有しています。新しい色は足していません

撮り直し：`node design/capture-current.mjs`
（現行画面を撮り直し、`design/index.html` の中へ data URI として埋め込み直します。
埋め込んでいるのは、**ファイル単体で開いても画像が出るようにするため**です。
Finderから開く・Claudeのプレビューパネルで見る・メールに添付する、といった場合に
隣の `current/*.png` を読みに行けず、画像だけ欠けるのを防いでいます。）

## 進める順番

| 案 | 中身 | なぜこの順か |
|---|---|---|
| **A** | 土台を整える（ナビ・情報の優先順位・学習のステップ化） | Aをやらないと、Cで作る価格画面もノイズの中に埋もれる |
| **C** | 有料商品として見せる（価格画面・無料の区切り） | 売上に直結する。Aの上でないと効かない |
| **B** | 習慣ドリブン（ストリーク・通知・週次） | 売れ始めてから効く。今回は完了画面だけ先に受け皿として作る |

## 案A — 画面ごとの対応表

| 画面 | 変えること | 触る場所 |
|---|---|---|
| 全体 | 上の4タブを**下タブ**へ。ヘッダーは細いバー1本に。約300px（画面の12%）を中身に返す | `.top` / `.nav-tabs` / `.bottomnav` のCSS、`setupNavTabs()` |
| 今日 | 主役を**学習カード1枚**に絞る。復習と模試は小さい2枚へ降格。所要時間（15分）を添える | `renderHome()` |
| 今日 | **模試を設定から昇格**。今日画面の常設カードに | `renderHome()` / `renderSettings()` |
| 今日 | 連続日数と今週の帯を追加（completedの日付から出す） | `renderHome()`、`state` に日付の記録を足す |
| Day学習 | **4ステップに割る**（単語→文法→聞く→解く）。上に進捗バー、下は「次へ」1つ | `render()` の day 分岐 |
| Day学習 | 「前の日／Day選択／次の日」と「前／完了／次」の重複をやめ、左上を「✕ 今日へ」に | `.daybar` / `#bottomNav` |
| Day学習 | 単語は1語ずつめくる。5語を一度に並べない | `render()` の vocab 部分 |
| 完了 | **完了画面を新設**。連続日数・その日の数字3行・次の2択 | `toggleComplete()` の後に画面を1つ足す |
| 設定 | 4グループに割る（アカウント／学習／表示／その他）。選択肢は行に畳む | `renderSettings()` |
| 設定 | 「購入を復元」を常設 | `renderSettings()` + `fetchPaidContent()` |

## 案C — 画面ごとの対応表

| 画面 | 変えること | 触る場所 |
|---|---|---|
| 価格 | **価格画面を新設。** いまは値段がアプリ内に一度も出ず、🔒を押すとそのままGoogleログイン→Stripeへ飛ぶ | `lockedDayHTML()` を全面書き換え |
| 価格 | 無料と有料の比較表。買い切りであることを価格の真横に | 同上 |
| 価格 | **クーポン欄を折りたたむ。** いまは購入ボタンより上にあり、全員に割引の存在を知らせて離脱させている | 同上 |
| 価格 | 「購入を復元」を常設。機種変・再インストールの受け皿 | 同上 ＋ 設定 |
| 無料の区切り | **Day 7 完了時の画面を新設。** 1週間やり切ったことを先に認め、Day 8 の中身を本物で見せてから価格へ | 完了画面の分岐 |
| 単語 | 全498語を出して未購入分に🔒。いまは35語しか見えず、教材の厚みが伝わらない | `renderVocabScreen()` |
| 購入 | ログインを購入の前提にしない（先に決済し、あとで紐付け） | `startCheckout()` ＋ `worker-paywall` |

比較表に入れている数字は実データから数えたもの。無料（Day1-7）＝単語35語・音声7本・ミニテスト77問・作文14問、
全90日＝498語・90本・986問・180問。

## 先に直したほうがいいもの（案を待たずに）

1. **ブックマークタブにDay画面の下ナビ（前・完了済み・次）が出ている。**
   `render()` が `bottomNav` を表示してから bookmark で早期リターンしているため。
   押すと関係ないDayの完了状態が変わる。実質バグ。
2. 受験予定日が `mm/dd/yyyy` のまま（`<input type="date">` のロケール未指定）
3. 初回起動の「スキップして始める」がボタン内で改行する
4. ブックマークでピンインが二重に出ている
5. 決済まわりが `alert()`。アプリ内トースト（`hsk-toast`）があるのに使っていない

## 実装するときの注意

- 画面遷移は必ず `goView()` を通す（`currentView` 1つで持つ設計）。新しい画面（完了・価格）も値を足して同じ経路に乗せる
- `LESSONS.length` ではなく `TOTAL_DAYS`（固定90）を使う。未購入だとDay8-90は存在しない
- 色は `:root` の既存トークンだけ。セージ／アプリコット／ブラッシュの3色で足りないか先に考える
- 丸ゴシック（Zen Maru Gothic）は見出し・ボタン・数字だけ。読ませる文章は Zen Kaku Gothic New
- **下タブへの変更は `tests/nav-test.mjs` が落ちる**（`.nav-tab` が4つあることを見ている）。テストも同時に直すこと
- 変更したら `node tests/run.mjs` を必ず通す
