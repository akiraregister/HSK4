# テスト

`index.html` は約900KBの単一ファイルで、ビルドもフレームワークもありません。
そのぶん壊れたことに気づきにくいので、実ブラウザで画面を操作して確かめるテストを置いています。

実際にこれで拾ったバグの例：

- 削除した関数への `window.*` 代入が残り、起動時に全体が停止していた
- `const` の一時的死角で例外が出て、`catch` が握りつぶし機能が黙って無効化されていた
- イベント名がプロパティに上書きされ、計測ログに名前が残っていなかった
- ブックマークの格納形が違い、一覧が `b.id.match` で落ちていた
- 復習の離脱計測がボタン経由しか拾えていなかった

## 動かし方

```bash
npm i playwright          # 初回のみ
node tests/run.mjs        # 全スイート（静的サーバーは自動で立ち上がります）
node tests/run.mjs nav lp # 指定したものだけ
```

Chromium が既定の場所に無い環境では、実行ファイルを指定します。

```bash
CHROMIUM=/path/to/chrome node tests/run.mjs
```

## スイート

| 名前 | 見ているもの | 項目数 |
|---|---|---|
| `nav` | 4タブの遷移、設定パネル、学習→完了→復習の一巡 | 36 |
| `onboard` | 初回の級診断、スキップ、HSK3／4／5以上の3分岐 | 16 |
| `mock` | 模擬試験の一巡、受験日カウントダウン、仕上げモード | 17 |
| `track` | 計測イベント、復習離脱の両経路、設定の集計表示 | 15 |
| `lp` | LPの横スクロール、CTA位置、計測、アプリへの導線、2つのデモ | 19 |
| `sw` | Service Worker のプリキャッシュとオフライン起動 | — |

## 書くときの約束

- **本番にテスト用のフックを足さない。** モジュールスコープの変数は外から読めないので、
  画面に出ている文字（例：見出しの「模試 1 / 40」）から読み取ります。
- **セレクタは `#content` か `#settingsPanel` に限定する。** 設定パネルは常時DOMにあるため、
  `button:has-text("受ける")` のような指定が別画面のボタンに当たります。
- **アプリの起動を待つ。** 900KBあるので、遷移直後は3秒ほど見ておかないと取りこぼします。
