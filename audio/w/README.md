# 単語・例文の録音

**まだ1本も作っていません。**`index.json` が空なので、アプリは録音を探さずに
端末の読み上げ（Web Speech）へ回しています。

## なぜ要るか

iPhoneの消音スイッチは**内蔵スピーカーにしか効かない**。同じ端末で確かめた結果：

| | スピーカー | イヤホン |
|---|---|---|
| 録音（`audio/dayN.mp3`） | 消音でも鳴る | 鳴る |
| 読み上げ（Web Speech） | **消音だと黙る** | 鳴る |

ブラウザからは消音状態も再生経路も触れないので、**確実に鳴らすには録音を持つしかない**。

## 作り方

```
node audio/build-word-audio.mjs --dry-run --words     本数だけ見る（鍵は要らない）
GOOGLE_TTS_KEY=xxxx node audio/build-word-audio.mjs --words
```

- `--words` は単語498本だけ（約2〜3MB）。例文と文法例文で容量の8割を使うので、
  まず単語だけ作って様子を見るのがおすすめ
- 全部なら `--words` を外す（1,207本・12〜16MB）
- **すでにあるファイルは作り直さない。**途中で止めても、もう一度叩けば続きから進む
- 最後に `index.json` を書き直す。**これを消すとアプリが毎回404を取りにいく**ので、
  mp3を手で消したときは生成器をもう一度叩いて索引を作り直すこと
