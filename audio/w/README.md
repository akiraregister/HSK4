# 単語・例文の録音

**1,207本（14.8MB）そろっています**（2026年9月）。単語498・例文492・文法例文217。
**アプリが鳴らす文字列は全部あるので、欠けはありません。**
`index.html` の内容を増やしたら、下の手順でもう一度叩いて差分だけ作ること。

## なぜ要るか

iPhoneの消音スイッチは**内蔵スピーカーにしか効かない**。同じ端末で確かめた結果：

| | スピーカー | イヤホン |
|---|---|---|
| 録音（`audio/dayN.mp3`） | 消音でも鳴る | 鳴る |
| 読み上げ（Web Speech） | **消音だと黙る** | 鳴る |

ブラウザからは消音状態も再生経路も触れないので、**確実に鳴らすには録音を持つしかない**。

## 作り方

```
node audio/build-word-audio.mjs --dry-run --words     本数だけ見る（鍵は要らない）
GOOGLE_TTS_KEY=AIza... node audio/build-word-audio.mjs --words
```

**`AIza...` の部分は実際のキーに置き換えること。**案内文のプレースホルダを
そのまま貼ってしまう事故が起きたので、いまは鍵の形（`AIza` で始まる39文字）を
先に見て、叩いた瞬間に止まるようにしてある。

- `--words` を付けると単語だけ。付けなければ全部（例文と文法例文を含む）
- **すでにあるものは作り直さないので、いつ叩いても差分だけ**で済む
- **すでにあるファイルは作り直さない。**途中で止めても、もう一度叩けば続きから進む
- 最後に `index.json` を書き直す。**これを消すとアプリが毎回404を取りにいく**ので、
  mp3を手で消したときは生成器をもう一度叩いて索引を作り直すこと

## ファイル名

中文そのものから決まる（`audioKey()`＝FNV-1a 32bit）。**一覧は置かない。**
置くと、未購入のDay8-90の例文までURL一覧として公開されてしまう。
`index.json` はハッシュだけなので、中文は漏れない。

**`index.html` 側の `audioKey()` と必ず同じ結果にすること。**ずれると録音が
見つからず、黙って読み上げへ落ちる（＝消音で鳴らないまま）。
`tests/listen-test.mjs` が両者の一致を見張っている。
