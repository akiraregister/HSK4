# 販促素材（App Storeスクリーンショット／LPモックアップ）

アプリを売るときに要る絵と、その元になる「誰のため・何が特徴」の整理を置いている。
画像はすべて **アプリを実際に操作して撮ったもの**（`capture-app.mjs`）で、描き起こしではない。
文言や画面を変えたら撮り直すこと（手順は末尾）。

---

## 1. 誰のためのアプリか

**一次ターゲット：中国語を仕事と生活の両方で使う、日本語話者の社会人。**

| | 誰 | その人の困りごと |
|---|---|---|
| 主 | 駐在・出張で中国語を使う人 | 会議でも食堂でも使う。教科書の例文が現場と合わない |
| 主 | HSK3に受かって、次を探している人 | HSK4は累計1200語。3から600語増えるが、どう割るか分からない |
| 副 | 独学で続かなかった人 | 単語帳のどこまでやったかを管理できずに止まる |
| 副 | 昔かじって、やり直す人 | いまの自分の位置が分からない |

**向かない人（LPにも正直に書く）**

- 今週末の試験に間に合わせたい人（積み上がるまでに時間がかかる作り）
- HSK5以上の人（級診断で「易しすぎる」と正直に出る）

## 2. 何が特徴か

数字はすべて `index.html` の実データから数えたもの（2026-09時点）。

| 特徴 | 中身 | 裏づけ |
|---|---|---|
| **終わりがある** | 90日で完走するカリキュラム。1日15分、単語5個・文法3つ | `LESSONS` 90日 |
| **迷わせない** | 開くと「新しく覚える」と「思い出す」の2枚だけが出る | 今日画面 |
| **忘れる頃に出る** | 間隔反復（SM-2）。手応え4段階で次の出題日が決まる | `srsGrade()` |
| **耳もやる** | 全90日にネイティブ音声の会話。1回だけ再生、聞き終えるまで文字は出ない | `audio/day1-90.mp3`（90本） |
| **使えるか試す** | 毎日5問。選択4＋並べ替えか作文1。作文はAIが採点して直す | ミニテスト986問（選択716・語順90・作文180） |
| **位置が見える** | 40問30分の模試。分野ごとの正答率、間違えた範囲は復習へ | 10日ぶん完了で解禁 |
| **例文が現場寄り** | ビジネスと生活を混ぜている | 頻出498語・文法222項目 |

**ひとことで：**
> 中国語を仕事でも生活でも使う日本語話者が、1日15分・90日でHSK4の語彙と文法の骨格を作るための、
> 「開けば今日ぶんだけが出ていて、忘れる頃にもう一度出してくれる」アプリ。

## 3. App Storeスクリーンショット（`appstore/`）

`appstore/index.html` が版下、`appstore/out/01〜07.png` が書き出し。
**1枚 1290×2796px**（iPhone 6.9インチ＝15/16 Pro Max。App Store Connectはこのサイズだけ入れれば
他の端末サイズへ自動で流用される）。

### 7枚の訴求

競合（単語アプリ／Anki／総合中国語アプリ／HSK問題集）に対して言えることだけを並べている。
「HSK4特化」のようなカテゴリ宣言は、ほぼ全社が言うので単独では枚を使わない。

| 枚 | アイブロウ | 見出し | サブ | 何に対する優位か |
|---|---|---|---|---|
| 01 | 日本語話者のためのHSK4対策 | HSK4に特化。90日完結。 | 頻出498語と文法222項目を、90日ぶんに。 | 終わりを明示しない教材全般 |
| 02 | これ1本で足りる | 毎日15分だけ。単語も、文法も、リスニングも、ミニテストも。 | 単語5個・文法3つ・音声1問・テスト5問。 | 単語アプリ＋音声教材＋問題集の3本立て |
| 03 | 間隔反復（SM-2） | 忘れる頃に、もう一度出題して、効果的に復習。 | 手応えを4段階で押すだけ。あとは自動です。 | 単語帳。Ankiは自分でカードを作る手間が残る |
| 04 | 文法222項目すべてに | 日本人が間違えやすいところを独自解説。 | 例：日本語の過去を、全部 了 にしないこと。 | 英語圏発の総合アプリ、中国語だけの教材 |
| 05 | 本番は听力が約3分の1 | 90日分の音声を全部カバー。 | 再生は1回だけ。聞き終えるまで文字は出ません。 | 音声のない単語アプリ |
| 06 | 作文180問 | AIによる添削。 | 点数と「自然な言い方」が返ります。 | 独学で埋まらない「書く」 |
| 07 | 40問30分 | 模擬試験で、苦手な分野が見える。 | 間違えた範囲は、そのまま復習に送れます。 | 解くだけの問題集 |

**並べる順**：App Storeの検索結果で見えるのは最初の3枚。
01（何のアプリか）→ 02（これ1本で足りる）→ 03（他と違う仕組み）の順は変えないほうがいい。
枚数を絞るなら 05〜07 が削る側。

### 見た目の方針

**上半分を、墨（`#2A2724`）かアンバー（`#F2A227`）のベタ塗りにしている。** どちらもアプリの
ボタンで既に主役の2色で、新しい色は足していない。最初はアプリと同じクリーム＋淡い3色で
作ったが、App Storeの一覧では彩度の高い他社のスクショに埋もれて、余白が「抜け」ではなく
「未完成」に見えた。ベタ帯にすると一覧でも拾われる。

- 帯の色は 墨 → アンバー → 墨 … と交互（01墨・02アンバー・03墨・04アンバー・05墨・06アンバー・07墨）
- 帯の下端は手書きの波で切る（アプリの背面シェイプと同じ語彙）。波の形は4種類を使い回す
- 帯の高さは `min-height:930px` で全枚そろえる。見出しが1行の回だけ帯が浅くなると、
  並べたときにリズムが崩れるため
- 淡い3色（セージ／アプリコット／ブラッシュ）は、帯の下のクリーム側に1つだけ敷く
- ロゴは01だけ。全枚に置くと縦を食う割に情報が増えない

### 4つの構図を回している

7枚とも「端末まるごと」にすると、全部同じ絵に見えるうえ、画面のどこの話か分からなくなる。
そこで枚ごとに構図を変えている。**新しい枚を足すときも、この4つのどれかに当てはめること。**

| 型 | 中身 | 使っている枚 | 向いている場面 |
|---|---|---|---|
| A | 端末まるごと | 01・07 | 画面全体がそのまま訴求になる回 |
| B | 端末＋その中の一箇所を丸で囲って拡大 | 02 | 訴求点が画面の**小さな一部**のとき |
| C | 端末枠を使わず、カード1枚を大きく | 04・06 | 文字を読ませたい回 |
| D | カード2枚を重ね、前→後の流れを見せる | 03・05 | 操作の前後で意味が出る回（表→裏、再生前→設問） |

**型Bを、画面のほとんどを占めるカードに使わないこと。** 同じ絵が大小で二度出るだけになり、
かえって分かりにくくなる（実際に05で一度やって失敗した）。

丸で囲む位置は手で数えない。`capture-app.mjs` が撮影時に対象の座標を
`shots/regions.json` に書き出し、版下側がそれを表示倍率で変換して置いている。

## 4. LPモックアップ（`lp-mockup/`）

`lp-mockup/index.html` を Safari で開くとそのまま読める。`lp-mockup/out/` に全体像のPNG（スマホ幅・PC幅）。

**いまの `lp/index.html` から変えたところ**（現行LPは販売前提になっていない）：

| 項目 | 現行LP | モックアップ |
|---|---|---|
| 価格 | 「¥7,800 買い切り（予定）・まだ決めていません」 | **¥4,800の買い切り**。Day 1-7無料を前面に |
| リスニング | 「**入っていません**。他の教材と併用してください」 | **全90日ぶん入っている**ことを主要な特徴の1つに |
| 作文AI採点 | 触れていない | ミニテストの節で明示 |
| 級診断 | 「16問・約5分」 | 実際に合わせて **20問・約7分** |
| 冒頭 | いきなり「90日で、HSK4に届く。」 | 上に「中国語を仕事と生活で使う、日本語話者へ」を足し、誰向けかを先に言う |
| 画面 | HTMLで作ったモック | 実画面の写真 |

**本番へ入れるとき**は、`lp-mockup/index.html` の中身を `lp/index.html` へ移したうえで、

- 画像パスを `../marketing/shots/…` ではなく `lp/` 配下へ寄せる（または `og.png` と同じ扱いにする）
- 現行LPが持っている**計測（`track()`）と2つの触れるデモ**を戻す。モックアップでは落としてある
- `node tests/run.mjs lp` が通ることを確認する（LPのテストは19項目ある）
- 先頭の「モックアップ」帯（`.mockbar`）を消す

## 5. 作り直し手順

### 日本語フォントが入っている環境で撮ること

Macなら Hiragino があるので何もしなくてよい。**Linuxで撮る場合は要注意。**
既定のままだと `sans-serif:lang=ja` が **WenQuanYi Zen Hei（簡体字フォント）** に解決され、
Webフォント（Zen Maru Gothic / Zen Kaku Gothic New / Yomogi）に無い字だけが
中国語の字形で出る。日本語として見ると字体が崩れて、胡散臭い見た目になる。

```bash
apt-get install -y fonts-noto-cjk
```

そのうえで `/etc/fonts/local.conf` に、日本語は `Noto Sans CJK JP`、中文は `Noto Sans CJK SC`
を優先し、`WenQuanYi Zen Hei` を候補から外す設定を置く。`fc-match "sans-serif:lang=ja"` が
`Noto Sans CJK JP` を返せば正しい。

```bash
npm i playwright          # 初回のみ（Chromiumは既にある環境ならダウンロード不要）
node marketing/capture-app.mjs      # アプリの実画面を撮る → marketing/shots/
node marketing/capture-sheets.mjs   # 版下から書き出す → appstore/out/ と lp-mockup/out/
```

- `node marketing/capture-sheets.mjs appstore` / `... lp` で片方だけにもできる。
- 復習カードに出る単語や模試の点数は毎回変わる（実際に操作しているため）。気に入った回のものを残す。
- `GRADE=1 node marketing/capture-app.mjs` にすると、作文を**実際に採点サーバーへ投げて**
  採点結果の画面まで撮る。ネットワークが `hsk4-grader` に届く環境（＝手元のMac）で実行すること。
  届かないと「採点に失敗しました」の画面が撮れてしまう。
- **06（AIによる添削）だけ、画像が本来のものではない。** いまは採点前の入力画面を使っている。
  上のコマンドで `card-writing-graded.png` を撮り、版下の06の `card` をそれに差し替えると、
  点数と「自然な言い方」が返っているところまで見せられる。そのときは型Dにして
  「書いた → 直された」の2枚重ねにするのがいちばん伝わる。

## 6. 売る前に片付けること（この素材を作って気づいたぶん）

1. **App Storeで売るなら、いまのままでは出せない。** これはPWA（ブラウザで動くWebアプリ）で、
   App Storeに出すにはネイティブの器（WKWebViewのラッパー等）が要る。さらにAppleの規約では
   **アプリ内のデジタルコンテンツはApp内課金（IAP）必須**で、いま組んであるStripe決済は使えず、
   手数料も15〜30%かかる。¥4,800という価格はStripe前提の数字なので、App Storeへ出すなら
   価格そのものを組み直す必要がある。**まずはWeb（いまの形）で売り、反応を見てからApp Store、
   という順のほうが現実的。** この素材はどちらでも使える。
2. **`lp/index.html` の記述が実装に追いついていない。** 特に「リスニングは入っていません」は、
   全90日ぶんの音声が入っているいまは事実と違う。販売以前に直すべき。
3. **`legal/tokushoho.html` の事業者情報が未定。** LPの価格セクションからここへリンクしている。
4. リポジトリのPrivate化・Day8-90の切り出し・Stripeの本番切り替えは、ルートの `CLAUDE.md` の
   「⚠️ 販売開始前に必ず確認」のとおり。
